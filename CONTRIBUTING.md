# Contributing

Read README.md, AGENTS.md and docs/architecture.md. Use Node 22/24 and npm ci. Run npm run check, npm test, npm run build, npm run check:package and npm run test:browser. Include the rebuilt dist/haus-blick.js; HACS installs it directly.

Describe behavior, actual checks and remaining HA limitations. Use synthetic entities; never commit tokens, broker passwords, HA backups, sensor captures or private App sources. Keep editor and configuration validation aligned. Preserve SDK/three.js notices. Report HA/HACS/browser versions for bugs and redact personal names/locations. Security reports belong to SECURITY.md.
