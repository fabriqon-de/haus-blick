# Security

Report vulnerabilities privately through GitHub private vulnerability reporting when available, or through the repository owner's contact at https://fabriqon.de/impressum.html. Never put tokens, passwords, HA backups or personal sensor captures into public issues.

The card uses the current HA frontend session. It stores no credentials, connects to no broker and makes no direct device-service calls. Like any custom frontend code, it has access to the current HA context. Only the current development line is maintained; a stable support window will accompany a stable release.
