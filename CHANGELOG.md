# Changelog

## 0.2.0 — House, drawing import and garden

- Local prepared DXF / DrawingPlan JSON import with polygon preview, units, rotation, scale and explicit binding reconciliation.
- Full wall heights, real door/window openings, flat/gabled roof sections and outside/interior/plan/floor controls.
- Garden and terrace areas, procedural trees/shrubs/pots/beds, and existing HA outdoor sensor bindings.
- Backward-compatible rectangular configurations; one self-contained HACS bundle, no extra backend or MCP.
- Automated geometry, import and WebGL coverage; real HA/HACS and Companion App acceptance remains pending.

## 0.1.0 — Initial HACS development version

- Fresh frontend-only project using the public Fabriqon SDK.
- Configurable 3D rooms, existing HA entity bindings, updates, more-info and a visual editor.
- Self-contained HACS distribution with complete MIT notices.
- Automated tests; real HA/HACS acceptance remains pending.
