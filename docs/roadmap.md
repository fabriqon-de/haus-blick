# Roadmap

1. Erste Karte in einer tatsächlichen HA-/HACS-Instanz abnehmen und Bedienung verbessern.
2. Raum-/Markereditor, später mehrere Etagen und Tür-/Fenstergeometrien.
3. Begrenzten, validierten Zeichnungs-/Modellimport vorbereiten; SDK-DXF-Bausteine sind noch kein ausgelieferter Kartenimport.
4. Eine Integration oder einen Server erst ergänzen, wenn ein konkreter Bedarf besteht, den das HA-Frontend nicht deckt.

MCP bleibt eine gesondert zu entwerfende Idee. Das Frontend stellt keinen offenen MCP-Server bereit. Eine eigene MQTT-Anbindung ist für vorhandene HA-Entitäten nicht erforderlich.
